This optional addon connects Community Meetings follow-ups with Odoo
Project. It lets users associate existing Project tasks with agenda
points and create tasks from a meeting. Company settings and meeting
series can define default project scope and the task requirements for
resolving TODO agenda points.

Usage
=====

Install this addon with Odoo Project. From an agenda point, link an
existing task or create a task in an available project. Configure
project selection and task requirements in the company or meeting series
settings. Project task access and company compatibility are checked when
linking and resolving points.

See the `Project integration
guide <https://oyale.github.io/odoo-meetings-minutes/html-en/integrations/project.html>`__.
