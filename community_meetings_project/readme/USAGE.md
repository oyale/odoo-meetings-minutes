Install this addon with Odoo Project. From an agenda point, link an existing
task or create a task in an available project. Configure project selection and
task requirements in the company or meeting series settings. Project task
access and company compatibility are checked when linking and resolving points.

When every task linked to a Project follow-up is completed, the follow-up is
completed as a delegated effect of the task update. The task writer still needs
normal Project write access, but does not gain access to its meeting or follow-up
record. Reopening a task does not reopen a completed follow-up. Approved minutes
remain unchanged when linked tasks change.

See the [Project integration guide](https://oyale.github.io/odoo-meetings-minutes/html-en/integrations/project.html).
