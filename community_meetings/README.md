# Community Meetings

[![Odoo 18.0](https://img.shields.io/badge/Odoo-18.0-714B67.svg)](https://github.com/oyale/meeting-minutes/tree/18.0)

[![Maturity: Beta](https://img.shields.io/badge/maturity-Beta-yellow.svg)](https://odoo-community.org/page/development-status)

Community Meetings provides a structured workflow for preparing, running and
approving operational meetings. Meeting series provide reusable defaults;
agenda points retain their identity across meetings, while each participation
records discussion notes, decisions, follow-ups and minutes for that session.
Approved minutes are stored as immutable revisions with a generated PDF.

## Usage

Create a meeting series to define recurring meeting defaults, or create a
standalone meeting. Use the guided meeting and agenda wizards to select the
date, attendees and agenda points. During the live meeting, record discussion
notes, agreements, dissents and follow-up work on each point. Prepare the
minutes and submit them for approval when the meeting is complete.

Access is controlled by the Proposer, Reader, Editor, Approver and Manager
groups. See the [user and administrator guide](https://oyale.github.io/meeting-minutes/)
for role details, configuration and workflows.

## Configuration

Administrators can configure meeting roles, agenda types, meeting kinds,
dissent reasons and follow-up kinds. Series can define default attendees,
estimated duration, agenda behavior and follow-up policies. Refer to the guide's
administration section for configuration details.
