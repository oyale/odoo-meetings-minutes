# Notas de versión

Esta página recoge los cambios visibles para los usuarios en cada versión de
Odoo Meetings Minutes. Las notas se agrupan por módulo y se generan a partir de
fragmentos de Towncrier antes de publicar cada versión.

El registro mediante fragmentos comienza después de la versión de referencia
publicada `18.0.20261018.1`; no se reconstruye el historial anterior.

Las notas se publican en inglés. Usa el selector de idioma de la parte superior
para consultarlas.
