This optional example addon demonstrates how to extend Community
Meetings with a custom meeting kind and add extension-specific data to
the meeting snapshot. It is intended as a reference for developers
building their own integrations and is not required for normal meeting
workflows.

**Table of contents**

.. contents::
   :local:

Usage
=====

Install ``community_meetings`` first, then install this addon to see the
example meeting kind and extension behavior. Use the source code and
tests as a starting point for custom addons; do not depend on this
example in production workflows.
