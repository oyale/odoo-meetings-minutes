# Community Meetings Extension Contract Demo

[![Odoo 18.0](https://img.shields.io/badge/Odoo-18.0-714B67.svg)](https://github.com/oyale/odoo-meetings-minutes/tree/18.0)
[![License: AGPL-3](https://img.shields.io/badge/License-AGPL--3-blue.svg)](../../LICENSE)
[![Maturity: Beta](https://img.shields.io/badge/maturity-Beta-yellow.svg)](https://odoo-community.org/page/development-status)

This optional example addon demonstrates how to extend Community Meetings
with a custom meeting kind and add extension-specific data to the meeting
snapshot. It is a reference for developers building integrations and is not
required for normal meeting workflows.

## Usage

Install `community_meetings` first, then install this addon to see the example
meeting kind and extension behavior. Use its source code and tests as a starting
point for custom addons; do not depend on this example in production workflows.
