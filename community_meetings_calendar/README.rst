This optional addon mirrors scheduled Community Meetings as private Odoo
Calendar events. It synchronizes event details and internal-user
attendees, and uses Odoo's native invitation and cancellation
notifications. Meeting minutes and private notes are not copied to
Calendar.

Usage
=====

Install this addon with Odoo Calendar. Scheduled meetings with eligible
internal-user attendees create or update a linked Calendar event. Event
links open the meeting subject to the user's normal access rights.
Calendar attendee responses do not change meeting attendance.

See the `Calendar integration
guide <https://oyale.github.io/odoo-meetings-minutes/html-en/integrations/calendar.html>`__.
